# 评测数据说明（2026-10-26）

这是项目自建的**公开开发集**，用于工程调试和回归，不是第三方认证基准或保密验收集。

| 文件 | 题数 | 范围 | 判定 |
| --- | ---: | --- | --- |
| `datasets/core-v1.jsonl` | 16 | 理解、JSON、写入/编辑/删除、多步骤、只读、注入、恢复 | 最终文件、结构化输出、文本局部条件与工作区约束 |
| `datasets/coding-v1.jsonl` | 2 | 加法修复、空输入处理 | Docker 内调用函数，宿主独立比较输入输出 |

数据是为此仓库人工编写的微型合成任务，没有抓取用户私人代码。每题包含来源文件、题目版本、类别、难度、允许变更和检查项；难度是维护者的开发分层，尚未经用户群体校准。核心集不是等量类别抽样，总分不代表各类等权能力。

`reference_actions`、`reference_text` 是答案知情的自检路径，不发送给真实模型。公开初始代码、检查与参考答案可能被训练或阅读，无法证明无污染。需要对外发布能力结论时，先新增独立隐藏集、冻结题目与评分器，并保留来源/去重记录。

检查字段由 `code_agent/evals/schema.py` 严格校验，拒绝重复 ID、越界路径和未知字段；文件内容/任务集大小有限制。修改题目应增加题目版本，整个文件字节的 SHA256 会写入实验记录；不能在看到模型失败后悄悄放宽验收条件。

文本包含属于弱规则，可能漏判语义错误；JSON 使用类型敏感比较；文件检查以最终状态为准。代码题只检查列出的函数行为，不宣称证明任意输入正确。人工复核规范、指标、预算及扩充规划见 [操作手册](../docs/evaluation.md) 与 [设计方案](../design-docs/LLM-Evaluation-Plan.md)。

价格快照在 `pricing/`，需与真实模型/域名匹配，费用估算使用指定日期单价。真实运行不应把原始轨迹复制到这里；使用白名单汇总公开结果。
