# 稳定性修复：2026-10-23

本次目标是修复上传 GitHub 前已确认的启动、隔离与验证问题，保留现有架构。

## 变更

- CLI 和 TUI 改用提供依赖注入的子代理工厂包装，修复启动时缺少必需参数的问题。
- CLI 主代理和权限层共享同一个沙箱管理器。CLI/TUI 沙箱命令禁用宿主机回退，避免自动放行后因 Docker 不可用改变执行位置。
- 子代理继承父代理权限规则及计划模式；未获得允许的操作在子代理中拒绝。能力名称拼写错误不再扩大工具范围。
- 计划模式覆盖删除工具；删除和写入同一路径共用执行锁；删除工具支持按目标路径匹配权限规则。
- 权限包延迟加载管理器，消除独立导入沙箱策略时的循环依赖。
- 新会话采用规范化项目路径的固定长度哈希目录；旧 Base64 布局继续支持读取、续写和查找。
- 修正压缩测试的函数替换位置，修正出站代理测试中与“允许子域名”策略矛盾的测试目标。
- 补齐 pytest-cov 开发依赖；独立环境安装验证，避免依赖系统环境中恰好存在的包。
- 新增 README、GitHub 上传说明、忽略规则、文本换行约定、Windows 自动测试流程和依赖版本快照。
- 更新中英文总进度中的过期阶段状态，并明确历史架构记录的适用范围。
