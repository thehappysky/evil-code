### 实现边界

- `runtime/open_runtime` 统一获取客户端 → 创建工具 → 补充工具 → 创建 Agent → 运行 → 关闭客户端的生命周期，不依赖 CLI 或 TUI。
- `cli/assembly.open_agent_runtime` 集中父代理工具和 Hook 装配，TUI 只传入其 Agent 适配器和审批展示参数；子代理使用相同的底层资源管理协议，保留自己的有限工具集与继承权限。
- 入口通过退出栈管理沙箱、MCP、记忆与跟踪清理；部分装配失败及取消也会清理。TUI 的所有会话客户端在本次界面退出时统一关闭，尚未实现切换后立刻回收旧客户端。
- 权限元数据配置移到共享 Hook 装配，CLI 与 TUI 均经过该步骤。沙箱不可用时禁止宿主机回退的规则保留。
- 模块级 `config/trace` 和部分历史字典式服务配置仍保留，后续可单独迁移；没有将本次工作描述为完成所有架构解耦。
